Lifesure is a comprehensive Life Insurance Management System built with Spring Boot that streamlines policy management, customer relations, and claims processing for insurance providers.
✨ Features

    Policy Management: Create, update, and manage insurance policies

    Customer Portal: Secure customer access to policy information

    Claims Processing: Streamlined claims submission and tracking

    Payment Integration: Premium payment processing with multiple gateways

    Reporting & Analytics: Generate insights with comprehensive reports

    Role-based Access Control: Secure authentication and authorization

    RESTful API: Modern API architecture for integration
